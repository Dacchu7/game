┌─ TROUBLESHOOTING ───────────────────────────────────────────────────────────┐
│                                                                             │
│  📖 Full Guide: FAQ.md                                                     │
│                                                                             │
│  ❌ Game won't start:                                                     │
│     → Clear cache: Ctrl+Shift+Delete                                       │
│     → Hard refresh: Ctrl+F5                                                │
│     → Check DevTools: F12 → Console                                        │
│     → Try different browser                                                │
│                                                                             │
│  ❌ Controls not working:                                                 │
│     → Make sure not paused (press SPACE)                                   │
│     → Click on game to activate                                            │
│     → Try arrow keys or WASD                                               │
│                                                                             │
│  ❌ Game is laggy:                                                        │
│     → Close other apps/tabs                                                │
│     → Try different browser                                                │
│     → Update graphics drivers                                              │
│                                                                             │
│  ❌ Sound not working:                                                    │
│     → Check volume (not muted)                                             │
│     → Some browsers need user interaction first                            │
│     → Try different browser                                                │
│                                                                             │
│  ❌ Mobile touch not responsive:                                          │
│     → Close other apps                                                     │
│     → Use landscape orientation                                            │
│     → Clear cache and reload                                               │
│                                                                             │
