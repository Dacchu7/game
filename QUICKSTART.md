# Quick Start Guide

## 🎮 Getting Started in 3 Steps

### Step 1: Open the Game
Simply double-click `index.html` in your file explorer and it will open in your default browser.

### Step 2: Play the Game
- Click **START GAME** button
- Use **Arrow Keys** or **WASD** to move Ganesha
- On **Mobile/Tablet**: Drag your finger to move
- **Collect** the golden offerings (Modak, Flowers, Incense)
- **Avoid** the red obstacles
- Complete the level before time runs out

### Step 3: Progress Through Levels
- Level 1: Collect 10 offerings in 60 seconds (Easy)
- Level 2: Collect 15 offerings in 50 seconds (Medium)
- Level 3: Collect 20 offerings in 40 seconds (Hard)

## 🎮 Game Controls

| Action | Desktop | Mobile |
|--------|---------|--------|
| Move Left | ← or A | Swipe/Drag Left |
| Move Right | → or D | Swipe/Drag Right |
| Move Up | ↑ or W | Swipe/Drag Up |
| Move Down | ↓ or S | Swipe/Drag Down |
| Pause | SPACE | N/A |
| Select Button | Click | Tap |

## 🏆 Scoring System

- **Modak (Golden Sweet)**: +10 Points ⭐
- **Flower**: +5 Points 🌸
- **Incense**: +8 Points 🔱
- **Hit Obstacle**: -20 Points ⚠️

## 💡 Tips & Tricks

1. **Collect Modak First** - They give the most points
2. **Plan Your Path** - Avoid obstacles while collecting
3. **Use Edges** - Move along screen edges for safety
4. **Watch the Timer** - Speed up as time runs out
5. **Practice Level 1** - Master the controls before harder levels

## 🐛 Troubleshooting

**Game not starting?**
- Clear browser cache and reload
- Try a different browser
- Ensure JavaScript is enabled

**Laggy gameplay?**
- Close other applications
- Close other browser tabs
- Use desktop version instead of mobile

**Sound not working?**
- Check browser volume
- Some browsers require user interaction first
- Check browser permissions for audio

## 📞 Support

If you encounter any issues, try:

2. Clearing browser cache
3. Updating your browser
